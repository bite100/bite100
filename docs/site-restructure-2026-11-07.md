# 第十三轮：全站界面重构（信息架构级）— 2026-11-07

## 定调（Ren 指令）

1. 「上边的贡献看板换个位置，界面是重构，不要把以前的都留着不动。」——本轮是信息架构级重构，不是换皮：整站重新组织，老布局该拆就拆、该挪就挪。
2. 「hy 不连钱包也能看行情」——未连接钱包时，交易主屏必须完整可见、可浏览，对标 Hyperliquid 的公开行情模式。

旧链接兼容：`?tab=` 旧值自动映射——`orderbook→trade`、`vault→assets`、`governance→govern`（治理子页）、`contribution→govern`（贡献奖励子页）、`swap/data/bridge` 同名保留。

## 交易主屏未连接可见性（逐区）

| 区域 | 未连接状态 | 数据源/说明 |
|---|---|---|
| 顶部信息条 PairStatsBar | 可见 | 节点 `/api/trades` 推导，无数据时显示 `—` |
| K 线 KLineChart | 可见 | 节点成交聚合；加载失败显示错误文案，无数据显示「暂无 K 线数据（尚无成交记录）」（本轮补齐） |
| 盘口 OrderBookWidget | 可见 | 节点 `/api/orderbook` 轮询；本轮起区分「节点未连接」与「暂无盘口」两种空态 |
| 最新成交 RecentTradesWidget | 可见 | 节点 `/api/trades` 轮询；本轮起区分「节点未连接」与「暂无成交」 |
| 成交记录页签 | 可见 | 公开成交，与右栏同源；节点失败显示未连接空态（本轮补齐） |
| 当前挂单 / 历史订单页签 | 空态 | 显示「连接钱包后查看订单」；节点已连接但未登录亦然，不报错 |
| 余额页签 | 空态 | 显示「连接钱包后查看余额」 |
| 下单面板 LimitOrderFormWidget | 空态 + CTA | 表单可见；面板内新增连接 CTA（StandardConnect）；提交按钮禁用，滑杆禁用，余额行显示连接提示 |
| 撤单 | 需连接 | 未连接无个人挂单，天然无撤单入口；已连接时走原签名撤单管道，未改 |
