## 2. 改写口径（Ren 2026-11-07 北极星定调）

1. **定位**：比特100 = 链无关的 P2P 去中心化交易所——打开网站、连接钱包，资产在哪条链都能交易。
2. **gas 口径（准确性红线）**：gas 由中继代付，用户无需自备原生代币；代付的 gas 在结算时**由交易双方对半分摊**回收。全站不出现「零 gas」「免 gas 费」类表述，统一写「无需自备原生代币 / 由中继代付」。
3. **手续费**：0.01%，从成交金额中以用户所持代币扣除。
4. **测试网诚实标注**：页眉副标题与连接条明确标注测试网，不使用主网正式运营的口气。
5. **语气**：可信、克制；不喊口号、不夸大（删除「主流 AMM 滑点 0.5%+」类无据对比表述）。
6. **一致性**：全角标点统一（`...`→`…`、半角冒号→全角）；去掉状态文字中的 emoji 前缀（✅⏳⏰❌📊💰🔄）；代币一律用符号 TKA/TKB（原 Token A/Token B 仅作合约语境保留）。

6. **挂单不冻结 Vault 余额（行为提示，非文案）**：核查 Vault 合约确认——余额为单一映射，挂单不锁定资金，提取只校验余额；结算是成交时才扣款。因此用户提空 Vault 后，未成交挂单成交时会结算失败。本轮文案已如实提示（存入/提取/下单三处）；是否给挂单加余额锁定属产品逻辑决策，未在本轮处理。
