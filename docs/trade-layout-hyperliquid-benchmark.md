## 定调

- **布局对标 HY**：交易主屏（导航「买卖」页，即 Dashboard）的信息架构按 Hyperliquid 交易页的公开布局重排（Ren 指令）。
- **皮肤保留第十一轮 B 极简设计系统**：浅灰底 `#F7F7F8`、白卡大圆角、强调色 `#FF007A`、Inter + 等宽数字、token 变量体系全部不变；本轮只新增一个 token `--b100-up-bg: #ECFDF3`（买盘深度条底色，取自 theme up 色阶 0 号）。密度上去了，视觉语言没有变回深色终端、没有换色。
- 改动范围：仅 `frontend/`；contracts/、node/、sdk/ 零改动；功能与接线零改动（chains.ts 双链地址、签名下单、合约调用、RainbowKit、AMM 全部保留原路径）。

## HY 有而我们没有的（产品缺口，只记录、不画假控件）

Bit100 是**现货订单簿 + AMM**，没有杠杆与永续。以下 HY 元素在本应用中不存在，本轮未做任何占位或假控件：

| HY 元素 | 缺口性质 |
| --- | --- |
| 杠杆倍数滑杆、逐仓/全仓、保证金 | 产品不存在（无杠杆） |
| TP/SL（止盈止损）、只减仓、强平价格 | 产品不存在（无永续持仓） |
| 标记价格 / 指数价格 / 资金费率 / 预言机价 | 产品不存在（现货无此概念） |
| 持仓表（仓位大小、开仓均价、未实现盈亏） | 无持仓概念；最接近的实体是「余额」页签（钱包 + Vault 余额） |
| 市价单 | 订单模型仅有限价单；下单面板的订单类型如实锁定为「限价单」并注明 |
| Post-Only / IOC / FOK 等高级订单选项 | 订单模型不支持（订单字段仅价格/数量/24h 过期） |
| 多交易对市场列表 / 交易对切换 | 全应用只有一个交易对 TKA/TKB，顶部信息条为固定展示 |
| 深度图（Depth Chart） | 盘口仅有深度条，未做聚合深度曲线图 |

## 拖拽网格让位说明（按指令的取舍）

第十一轮刻意保留的 Dashboard 可拖拽网格（react-grid-layout），本轮按 Ren「布局对标 HY」的指令**让位于固定 HY 式确定性网格**：交易主屏不再可拖拽/缩放，布局由 `TradeScreen.css` 的 grid 模板决定。

- localStorage 中旧的布局数据（键 `bite100_dashboard_layout`）不再被读取，留存无害，不做迁移。
- `react-grid-layout` / `react-resizable` 依赖暂未从 package.json 移除（避免本轮连带锁文件变更），交易主屏已无任何引用；后续清理依赖时可一并摘除。App.css 中旧 `.layout` 相关样式同理暂留未删。
- 其他页面（Swap、存提、完整订单簿、治理、贡献、跨链桥）不受影响。

## 数据诚实性说明

- 顶部 24h 统计以**最近一笔成交的时间**为窗口锚点（而非当前时刻）：测试网成交稀疏时，用当前时刻锚定会让窗口恒为空。窗口口径已在 `usePairStats` 注释中写明。
- 无成交且无盘口时，信息条各字段显示 `—`，不填任何默认数字。
- 「最新成交」的价格颜色按**与上一笔成交价的比较**着色，不代表 taker 买卖方向——节点成交记录没有方向字段，不臆造。
- 完整订单簿视图中的 CoinGecko「市场参考价」是外部参考价，不属于本交易对行情，未搬入顶部信息条。

## 存疑 / 取舍点（如实列出）

1. **下单按钮用了涨跌语义色（买绿 / 卖红）而非品牌玫红**：HY 的下单区即以买卖语义色为按钮色，交易语义优先；品牌玫红仍保留在滑杆、页签选中态、焦点环与「完整订单簿」入口等处。若 Ren 想全站主按钮统一玫红，此处可改回。
2. **盘口深度固定展示 10 档**（原 widget 为 8 档表格）：右栏高度与 K 线+页签区大体齐平；档数写在 `OrderBookWidget` 的 `DISPLAY_DEPTH` 常量，可调。
3. **下单面板新增了链上余额读取**（进入面板/切换方向时各一次 `balanceOf`），与完整订单簿同源同法；节点未配置时滑杆自动禁用，不阻断下单。
4. **页签区与完整订单簿存在功能重叠**（我的订单/撤单/成交在两处都有）：按 HY 布局，交易主屏必须自带表格区；完整订单簿保留为深度视图（含手续费面板、市场参考价、WS 增量动画等主屏没有的部分），入口在顶部信息条右侧。
