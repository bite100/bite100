## 风格定调

**B 现代极简风，对标 Uniswap**（Ren 拍板）：

- 浅色为主：页面底 `#F7F7F8`、卡片纯白，大留白；本轮只做浅色，未做深色模式切换（主题 token 已集中，后续加深色只需补一套变量）。
- 单一主强调色：玫红 `#FF007A`（brand 色阶 6 号），只用于主操作按钮、选中态、焦点环、关键链接。
- 涨跌色只在数据语义处小面积出现：涨/买 `#039855`、跌/卖 `#D92D20`（K 线蜡烛本体用 `#30A46C` / `#E5484D`），不再有币安式满屏红绿与黄色主按钮。
- 大圆角柔和卡片（24px）+ 轻阴影；排版层级靠字号 / 字重 / 间距拉开，不靠边框堆叠（边框仅作发丝线分隔）。
- 数字一律等宽字体（`--b100-font-num` / Mantine `fontFamilyMonospace`），保证订单簿、余额、手续费等列对齐。
- 交易动作是视觉主角：Swap 页改为 Uniswap 式居中主卡（最大宽 480px），顶栏只突出 Logo、链切换、连接钱包三件事。

## 视觉取舍点（如实列出，供 Ren 复核）

1. **强调色选了 Uniswap 同款玫红 `#FF007A`**，没有保留原币安黄，也没有用回图标原蓝色——选 B 路线即与 Uniswap 对齐，玫红是最具辨识度的落点；若想换回蓝色系，只需改 theme.ts 与 index.css 两处 token。
2. **深色模式未做**：Mantine 已切 `defaultColorScheme="light"` 且全站 CSS 变量化，深色后续可低成本补；本轮按「没有就只做浅色」执行。
3. **Dashboard 拖拽网格保留原样**：只换配色未改布局引擎，避免动到用户已保存的本地布局（localStorage）。
4. **K 线蜡烛色略区别于文字语义色**：蜡烛用更鲜明的 `#30A46C/#E5484D` 保证图表可读性，文字价格用较深的 `#039855/#D92D20` 保证对比度。
5. **「合约地址（验证用）」被折叠收纳**：内容未删，但默认不可见——这是顶栏降噪的一部分，若 Ren 日常验证频繁可再改回常驻。
